# Sandbar shark data

A dataset containing maturity and maternity data from 1087 female
sandbar sharks, *Carcharhinus plumbeus*, collected from the Gulf of
Mexico and western north Atlantic Ocean

## Usage

``` r
sandbar
```

## Format

A data frame with 1087 rows and 4 variables:

- FL:

  Fork length (mm)

- maturity_stage:

  Binary maturity stage: 0, immature; 1, mature

- maternity_stage:

  Binary maternity stage: 0, non-maternal; 1, maternal

- source:

  Data source - see below url

## Source

<http://dx.doi.org/10.1139/cjfas-2024-0031>
