# Sandbar shark data

A dataset containing maturity and maternity data from 1087 female
sandbar sharks, *Carcharhinus plumbeus*, collected from the Gulf of
Mexico and western north Atlantic Ocean. Data from two studies were
combined and maternal condition assigned to each individual for the
empirical case study of Harry et al. (2024).

## Usage

``` r
sandbar
```

## Format

A data frame with 1087 rows and 4 variables:

- FL:

  Fork length (cm)

- maturity_stage:

  Binary maturity stage: 0, immature; 1, mature

- maternity_stage:

  Binary maternity stage: 0, non-maternal; 1, maternal

- source:

  Originating study: `"Baremore"` or `"Piercy"`
